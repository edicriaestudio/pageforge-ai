# PageForge AI

Ambiente local para o MVP da plataforma autônoma de geração de Landing Pages.

## Configuração Local

1. Copie o arquivo de variáveis de ambiente:
   `cp .env.example .env`

2. Instale as dependências:
   `npm install`

3. Rode o servidor de desenvolvimento:
   `npm run dev`

4. Para rodar testes:
   `npm run test`
